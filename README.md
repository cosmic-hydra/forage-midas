# Midas
Project repo for the JPMC Advanced Software Engineering Forage program

## GitHub Codespaces

This repo is pre-configured for GitHub Codespaces. Click the button below (or follow [`.devcontainer/README.md`](.devcontainer/README.md) for full instructions):

1. **Create a Codespace** – Click **Code → Codespaces → Create codespace on flow** (the default branch).
2. **Rebuild container** – Command Palette → `Codespaces: Rebuild Container`.
3. **Build the project** – In the integrated terminal: `./mvnw -DskipTests package`
4. **Run the application** – `./mvnw spring-boot:run`
